How to Use

1. Login — Click "Login to Acceldata" in the popup. A new tab opens the ADOC SSO login page. Sign in there.
2. Return to extension — The popup automatically detects your login and advances. Close the login tab.
3. Open a Power BI report — Navigate to any report on app.powerbi.com.
4. Fetch data — Click "Fetch Reliability Data" in the popup, or use the floating ADOC panel on the right edge of the page.
5. Pin the panel — Click the pin icon to keep the sidebar docked to the Power BI page.
