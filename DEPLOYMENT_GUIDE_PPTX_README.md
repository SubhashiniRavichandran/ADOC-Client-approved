## 🆘 Troubleshooting

### Issue: Don't have Indium PowerPoint template

**Solution:**
1. Create new PowerPoint presentation
2. Apply Indium colors manually (Design → Colors)
3. Add orange accent bar using shapes (Insert → Shapes → Rectangle)
4. Add Indium logo to master slide (View → Slide Master)
5. Save as template for future use

### Issue: Screenshots are too large/small

**Solution:**
1. Select screenshot in PowerPoint
2. Format → Size
3. Set width to 50-60% of slide width
4. Maintain aspect ratio (lock proportions)

### Issue: Need to edit content

**Solution:**
- All content is in PPTX_Slide_Content.txt
- Edit text file, then copy updated content to slides
- Or edit directly in PowerPoint
