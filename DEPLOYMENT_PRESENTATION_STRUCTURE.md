- Verify contents include manifest.json

## SLIDE 12: Troubleshooting

**Layout:** Content slide with table format

**Title:** Common Issues & Solutions

**Content:**
| Issue | Solution |
|-------|----------|
| **Extension not visible** | Refresh chrome://extensions/ page<br>Pin extension to toolbar |
| **Login doesn't work** | Close auth tab manually<br>Click extension icon again |
| **Stuck on fetching** | Wait 10 seconds<br>Close and reopen popup |
| **No assets for all reports** | Verify datasets in ADOC<br>Check user permissions |
