SLIDE 3: INSTALLATION - STEP 1
================================================================================
[Indium logo top right, orange accent bar left]

Title: Installation Steps

Step 1: Download Extension
• Receive ADOC-Extension-v1.1.0.zip file
• Extract to your computer
• Verify contents include manifest.json

Step 2: Open Chrome Extensions
• Navigate to: chrome://extensions/
• Enable "Developer mode" (top right toggle)
• Click "Load unpacked"

================================================================================
SLIDE 4: INSTALLATION - STEP 2
================================================================================
[Indium logo top right, orange accent bar left]

Title: Load Extension

Step 3: Select Extension Folder
• Click "Load unpacked" button
• Browse to extracted chrome-extension folder
• Click "Select Folder"

Step 4: Verify Installation
✓ Extension appears in extensions list
✓ ADOC icon visible in Chrome toolbar
✓ Status shows "On"

SLIDE 12: TROUBLESHOOTING
================================================================================
[Indium logo top right, orange accent bar left]

Title: Common Issues & Solutions

Extension not visible:
→ Refresh chrome://extensions/ page
→ Pin extension to toolbar

Login doesn't work:
→ Close auth tab manually
→ Click extension icon again

Stuck on fetching:
→ Wait 10 seconds
→ Close and reopen popup

No assets for all reports:
→ Verify datasets in ADOC
→ Check user permissions
